# TLC witness behavior export

`scripts/export_tlc_trace.py` converts the pinned TLC 1.7.4 full textual
counterexample/witness output into typed JSON. The model workflow exports all
seven existing reachability/negative-vote behaviors and uploads them as
`tlc-witness-behaviors`. CTest runs parser regressions on Windows/Linux and
sanitizer jobs. Existing model bounds, invariants and expected exits are unchanged.

```sh
python scripts/export_tlc_trace.py --log witness-Leader.txt \
  --model formal/raft/ChoreoRaft.tla --config formal/raft/ReachLeader.cfg \
  --invariant NoLeaderWitness --output leader-behavior.json
```

The caller first requires TLC exit 12 and the exact expected invariant, as CI
already does. Export checks the invariant text, complete result footer,
contiguous state numbers, full/unchanged variable sets and complete value syntax.
Missing fields, difftrace, duplicate fields/keys, unsupported syntax and truncated
outputs fail. Limits are 16 MiB, 10,000 states, depth 64 and one million tokens
per value. No TLA+ expression is evaluated.

Records remain objects. Model values, sequences, sets and functions use explicit
`$model`, `$sequence`, `$set`, `$function` tags; function keys may themselves be
records. Quoted `"Nil"` remains distinct from model value `Nil`. Pretty-printed
empty functions can appear as `<<>>`; export preserves that textual sequence
representation rather than guessing a type. Future normalization must use the
model variable's declared meaning. Sets/functions preserve printed ordering;
a replay mapping must compare them by meaning, not JSON order.

Artifacts contain all variables and action source locations, the expected
invariant, TLC's version line, and SHA-256 of model/config/log. These hashes bind
provided files, not prove that an arbitrary log was generated by those sources;
CI's controlled invocation establishes that provenance for its own artifacts.
The JSON format is versioned at 1 and separate from the C++ trace versions.

## Evidence and remaining gate

Locally the exporter parsed the seven actual baseline TLC behaviors: 18-state
non-durable-vote counterexample, 18-state different-term leadership witness,
9-state leader witness, 14-state replication, 16-state commit, 20-state
application and 2-state offline witness. Each state preserved all 15 variables.
Six parser tests cover nested function/record keys, model values versus strings,
malformed/truncated values, wrong invariants, incomplete output, sequence gaps,
missing/duplicate variables and depth/state limits.

This is **behavior export only**. It neither replays the behaviors against C++
nor establishes projection correspondence, message identity mapping, justified
stuttering or refinement. Action source locations are not normalized protocol
actions. The existing model has no snapshot transitions. The next work must
connect exported inputs and durable completion context to a C++ replay driver,
state precisely which model/implementation steps correspond, and reject known
divergences. None of the remaining T1-B gates is marked complete by export.

[Observed mapping gaps](raft-model-mapping-gaps.md) record the concrete higher-term
vote staging discrepancy found while comparing actual exported states to C++.
